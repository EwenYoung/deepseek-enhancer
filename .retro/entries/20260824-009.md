助手回复导出是双数据源：原始 markdown 缓存只覆盖本页会话，历史会话必须走已渲染 DOM 提取+白名单净化。

- **症状**：HTML 导出里 markdown 原样文本（无标题/粗体/代码块），正文混入「css复制下载」按钮文字和「-1」引用角标；刚生成完回复就导出时正常
- **原因**：#ds-mini-asst-raw 缓存由 SSE 拦截写入，只覆盖当前页面会话实时生成的回复；历史会话回退 replyEl.textContent 丢 markdown 且混入装饰文本
- **解法**：历史路径用 extractRenderedReplyHTML：克隆 .ds-assistant-message-main-content → 删装饰 → sanitizeRenderedHTML 白名单净化 → 作为 renderedHTML 进气泡；判断路径看消息有无 renderedHTML 字段
- **适用条件**：chat-exporter；任何需要「原始 markdown」的新功能都要知道历史会话没有原始文本
