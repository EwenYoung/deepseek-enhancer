验证注入 CSS 效果先查目标元素 transition：立即读 computed style 会撞上过渡起始帧。

- **症状**：注入含 !important 的样式规则后立即 getComputedStyle 读到旧值/透明，表象是「规则没生效、有更高优先级规则压着」，差点把修复方向带偏
- **原因**：目标元素带 transition: background 0.3s（DeepSeek 消息气泡原生就有），注入/改值瞬间读取正处于过渡起始帧
- **解法**：先查 getComputedStyle(el).transitionProperty/transitionDuration；有 transition 就等过渡结束再断言，或临时 el.style.transition='none' 验证后还原
- **适用条件**：注入 CSS 的效果验证；本会话靠「注入后 sleep 600ms 再读」一次确认
