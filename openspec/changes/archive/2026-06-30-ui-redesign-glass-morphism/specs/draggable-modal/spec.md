# Draggable & Resizable Modal

## Overview
弹窗编辑框支持鼠标拖拽移动位置和四角拉伸窗口大小。

## Requirements

### R1: 拖拽移动
- 在编辑弹窗的标题栏区域按住鼠标拖拽，弹窗跟随移动
- 松开鼠标后停止移动
- 弹窗不能移出视口边界

### R2: 四角拉伸
- 弹窗的四个角落都有拉伸热点区域（右下角为主，但四个角均可）
- 鼠标移到角落时显示 `nwse-resize` / `nesw-resize` 光标
- 最小尺寸 480x360px
- 最大不超过视口

### R3: 删除确认弹窗不支持拖拽和拉伸（尺寸固定）

### R4: 状态仅本次会话有效
- 拖拽和拉伸后的位置、大小**不**持久化存储
- 每次打开弹窗默认居中，尺寸 680px 宽
- 无需存储位置信息
