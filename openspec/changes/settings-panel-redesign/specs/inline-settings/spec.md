# Inline Settings

## Overview
将底部折叠的设置区改为内联卡片形式，所有设置项在面板主内容区直接可见。

## Requirements

### R1: 布局
- 移除「设置」折叠区和 3 个标签页
- 设置卡片插入到导出与 Skills 之间
- 面板统一滚动（不分区）

### R2: 卡片样式
- 每个设置组（增强功能 / 面板设置 / API）使用独立卡片
- 卡片：圆角 10px，半透明背景，1px 边线
- 每行项：12px 字体，标签+开关左右排列
- 卡片间 margin 8px

### R3: 设置内容（不变）
- 增强功能：宽屏、主题（前后切换）、滚动条、输入框、语音、Token 速度
- 面板设置：透明度滑块（10-100%）
- API 设置：Tavily Key 输入框 + 保存/测试按钮

### R4: 动画
- 设置卡片在面板打开时依次渐入（0.3s，50ms 间隔）
- 开关/控件交互保持现有的 0.15s-0.2s 过渡

### R5: 兼容性
- 深色/浅色主题下卡片样式正常
- 所有设置功能的业务逻辑不变
